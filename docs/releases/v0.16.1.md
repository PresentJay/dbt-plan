# dbt-plan v0.16.1 — parser fix and easier first run

This patch release fixes inline unit-test CSV header parsing and gathers the
regression coverage and documentation improvements merged after v0.16.0.

## Fixed

- Parse inline unit-test CSV headers with Python's strict CSV parser rather than
  splitting on commas.
- Keep malformed, blank and duplicate headers as review-required uncertainty. They
  cannot establish a safe column set or hide a downstream risk.

## Coverage and documentation

- Add projection fixtures for PostgreSQL, BigQuery, Snowflake, DuckDB and Trino.
- Document warehouse-free reproduction, configuration and terminal-output precedence,
  the stats report, Windows development and the first-run onboarding path.

## Upgrade

```bash
pip install --upgrade dbt-plan==0.16.1
```

This release has no breaking CLI or API changes. Existing `0.16.0` consumers can
upgrade directly; the new parser is stricter when a fixture is malformed or cannot
provide reliable headers, so those cases may now require review as intended.

## Verification

Required CI covers Python 3.10–3.14 on Linux and Windows, the minimum sqlglot
version, built packages, real dbt/DuckDB execution, MCP and the composite Action.
The release workflow additionally checks the built package without skips before
publishing to PyPI, GitHub Releases and the MCP registry.
